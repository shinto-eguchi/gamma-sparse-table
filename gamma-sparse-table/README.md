# Log-Gamma Estimation for Sparse Contingency Tables

This repository contains the simulation code for the numerical experiments in

> **Log-Gamma Estimation for Sparse Contingency Tables under High-Leverage Sparse Noise**

The experiments study log-gamma estimation for high-dimensional sparse binary contingency tables.  The core example uses ten binary factors, all main effects and all pairwise interactions, and a clean sparse log-linear parameter.  Sparse-cell noise is then added to cells that are rare under the clean model, including a high-leverage stress setting.

## Main idea

Maximum likelihood uses the ordinary multinomial log score.  In sparse tables, a small number of rare observed cells can have high leverage for natural parameters.  The log-gamma score replaces this boundary-sensitive contribution by a power-weighted empirical term.  For positive gamma, cells assigned small fitted probabilities are attenuated.

The code compares:

- MLE, corresponding to `gamma = 0`;
- fixed positive gamma values, including `0.5`, `0.8`, `1.0`, and `1.3`;
- a Warwick--Jones type adaptive choice of gamma, using an estimated MSE on the fitted-distribution scale.

## Installation

A fresh Python environment is recommended.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -e .
```

```bash
python -m pip install -r requirements.txt
```

## Quick smoke test

The default scripts are intentionally modest so that a quick run finishes without a long computation.

```bash
python scripts/run_high_leverage_stress.py \
  --q 6 --n 600 --m-stress 10 --lambda-stress 2.0 \
  --n-reps 2 --b-resample 2 --n-jobs 1 \
  --out-dir results/test_high_leverage

python scripts/make_table3.py \
  results/test_high_leverage/high_leverage_stress_method_summary.csv \
  --out results/test_high_leverage/table3_markdown.md
```

This creates CSV summaries and figures in `results/test_high_leverage/`.

## Reproducing the main stress experiment

The high-leverage sparse-noise stress test used in the manuscript is generated by

```bash
python scripts/run_high_leverage_stress.py \
  --n-reps 60 \
  --b-resample 10 \
  --n-jobs 7 \
  --out-dir results/high_leverage_stress

python scripts/make_table3.py \
  results/high_leverage_stress/high_leverage_stress_method_summary.csv \
  --out results/high_leverage_stress/table3_markdown.md
```

For a more stable final run, increase `--n-reps` to `100` and optionally increase `--b-resample` to `12` or `20`.

## Diffuse sparse-noise gamma path

```bash
python scripts/run_diffuse_sparse_noise.py \
  --n-reps 80 \
  --n-jobs 7 \
  --out-dir results/diffuse_sparse_noise
```

This produces gamma-path summaries such as `gamma_sparse_rmse_summary.csv` and plots of all-parameter RMSE, active-parameter RMSE, and probability L2 error.

## Correct specification versus uniform noise

```bash
python scripts/run_uniform_noise.py \
  --n-reps 60 \
  --b-resample 10 \
  --n-jobs 7 \
  --out-dir results/uniform_noise
```

This compares the clean case and a uniform-noise contamination case.

## Output files

Typical high-leverage stress outputs are:

- `high_leverage_stress_method_results.csv`: replication-level method results;
- `high_leverage_stress_method_summary.csv`: Monte Carlo means and standard errors;
- `high_leverage_stress_wj_curves.csv`: WJ bias/variance/MSE curves by replication;
- `high_leverage_stress_wj_curve_summary.csv`: averaged WJ curve;
- `high_leverage_stress_active_rmse.png`: active-parameter RMSE bar plot;
- `table3_markdown.md`: manuscript-ready Markdown table.

The active-RMSE bar plot is useful for a quick visual check, but the manuscript table contains the more complete numerical summary.

## Notes on reproducibility

The scripts set fixed random seeds by default.  Monte Carlo numbers can still vary across library versions and BLAS implementations because optimization is numerical.  The important qualitative pattern in the high-leverage stress experiment is that positive gamma suppresses sparse-cell leverage relative to MLE, while the WJ-selected estimator is typically more conservative than the best fixed gamma chosen with knowledge of the clean target.
